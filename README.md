## About the Project

**Nu Visuales** is an interactive collection of visual resources exploring Nu's brand, product portfolio, and the **Abre Caminos credit card in Colombia**.

The site organizes product and brand research into focused pages, making the analysis easier to navigate and explore.

## Explore the Project

| Resource | Description |
|---|---|
| [Nubank Concept Map](https://estebanfernandezb.github.io/nu-visuales/nubank-mapa.html) | Interactive concept map with navigation, zoom, and expandable sections. |
| [Brand & Portfolio](https://estebanfernandezb.github.io/nu-visuales/nu-marca.html) | Overview of Nu's brand and product portfolio. |
| [Abre Caminos Card](https://estebanfernandezb.github.io/nu-visuales/nu-abre-caminos.html) | Product overview with interactive content and a financial calculator. |

## Highlights

- Interactive concept map with pan, zoom, focus, and expandable branches.
- Responsive pages designed for desktop and mobile screens.
- Product analysis presented through cards, tabs, and structured comparisons.
- Interactive tools to explore product characteristics.
- Consistent visual identity inspired by Nu's purple color palette.

## Built With

- **HTML5** for page structure.
- **CSS3** for responsive layouts, visual styling, and themes.
- **JavaScript** for interactive navigation, visualizations, and page controls.
- **GitHub Pages** for publishing the project.

The pages use a lightweight static-site approach, with no build step required to view the source locally.

## Run Locally

1. Clone or download this repository.
2. Open `index.html` in your browser.

Alternatively, start a local server from the project folder:

```bash
python -m http.server 8080
```

Then visit `http://localhost:8080`.
